# marius-ai-systems-portfolio

A sanitized public portfolio of AI systems work by **Matt McBride**.

This repository is a public-facing companion to private multi-agent AI systems work. It demonstrates architecture, workflow design, evaluation thinking, proof-gated agent operations, and revenue-focused AI automation without exposing private production code, API keys, client data, logs, or operational secrets.

## Current Focus

The active commercial track is **Marius Foreman**: an installed missed-call recovery and follow-up system for small home-services contractors.

The public acquisition wedge is **Lead Leak Scan** at [leadleakscan.com](https://leadleakscan.com): a free contractor diagnostic that identifies where a business is leaking leads through missed calls, weak follow-up, poor booking friction, and local visibility gaps.

The delivery path now includes live client-facing microsites:

## What This Portfolio Is Meant To Prove

- I can move from idea to deployed system.
- I can build with Python, FastAPI, GitHub workflows, webhooks, dashboards, and LLM providers.
- I understand agent safety, proof bundles, review gates, and human approval boundaries.
- I can translate AI tooling into practical business workflows instead of vague platform demos.

## What Is Intentionally Excluded

- `.env` files, API keys, tokens, secrets of any kind
- Private logs, run transcripts, or trace dumps
- Real client, customer, or prospect data
- Trading execution code, broker API integrations, or live order routing
- Internal domain names, private repository names, or operational hostnames
- Business-sensitive contract, pricing, or revenue details that should stay private
